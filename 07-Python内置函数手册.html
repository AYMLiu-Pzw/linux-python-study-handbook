理念篇：先搞懂函数是什么，再记函数

1. 函数 = 一台加工机器

进去的是原料（参数），出来的是产品（返回值）：

len("hello") # 原料 "hello" → 机器 len → 产品 5

2. 三条黄金规律

规律①：名字即用途。print打印、input输入、len长度(length)、sum求和、sorted排序——英文单词看懂，函数就懂一半。
规律②：括号是开关。函数名后面跟 ()才开工；不写括号只是把机器指给你看。
规律③：函数 vs 方法。函数是 len(x)（手拿工具加工）；方法是 x.split()（工具长在对象身上，点号调用）。

3. 最重要的两个函数（第一天就认识）

函数作用示例
print()打印到屏幕print("a", "b", sep="-", end="!") → a-b!
input()读键盘输入name = input("你叫什么：") → 停下等你输入；回车后 name = 你输入的文字

input() 拿到的永远是字符串！要算数先 int()。

4. 类型转换家族 = "工厂函数"

str() int() float() bool() list() tuple() dict() set() —— 都是把一种类型"加工"成另一种类型的工厂。见第 2 组。

5. 变量 = 贴了标签的盒子

age = 19 # 造一个盒子，贴上"age"标签，把 19 放进去。以后写 age 就等于是 19。

命名规律：见名知意（age、name、disk_usage）；英文小写，多词用下划线连接。

函数作用示例注意点
str()转字符串str(42) → "42"拼接字符串前常用

第 4 组 · 序列工具（range/enumerate/zip/sorted/reversed）

函数作用示例注意点
range()生成数列list(range(5)) → [0, 1, 2, 3, 4]
list(range(1,10,2)) → [1, 3, 5, 7, 9]
range(5) → range(0, 5)		终点不含；直接敲 range(5) 显示的是对象本身 range(0, 5)，要看数字得套 list()
enumerate()编号遍历for i, x in enumerate(xs, 1): → i 从 1 开始编号（不写第二个参数则从 0）第二个参数=起始编号
zip()拉链配对list(zip([1,2], ["a","b"])) → [(1, 'a'), (2, 'b')]zip() 本身返回迭代器，要列表得套 list()
sorted()排序（返回新列表）sorted([3,1,2]) → [1, 2, 3]
reverse=True 倒序		原列表不变
list.sort()原地排序（改原列表，返回 None）a = [3,1]; a.sort(); print(a) → [1,3]
与 sorted() 的区别：sort() 改原列表不返回新列表；sorted() 返回新列表不动原列表（进阶篇已统一用 sorted()）
reversed()反向list(reversed([1,2])) → [2, 1]要 list() 包一层

6.2 os / time 常用函数速查（运维最常用）

函数作用示例
os.getcwd()当前目录import os; os.getcwd() → '/home/你的用户名'
os.listdir(路径)列目录内容os.listdir(".") → 当前目录的文件名列表（内容以你机器实际为准）
os.path.join(a, b)拼路径（自动用对分隔符）os.path.join("home", "student") → "home/student"
os.rename(旧, 新)重命名/移动文件os.rename("a.txt", "b.txt") → 不报错就是成功（旧名消失、新名出现）
os.path.exists(路径)判断文件是否存在os.path.exists("a.txt") → True/False
os.path.getsize(路径)文件大小（字节）os.path.getsize("a.txt") → 数字（大小以你机器的文件为准）
os.path.getmtime(路径)最后修改时间（时间戳）os.path.getmtime("a.txt") → 数字（时间戳，值以你机器为准）
time.localtime(秒)时间戳 → 可读时间time.strftime("%F", time.localtime(时间戳)) → '2026-08-25'（示例）
time.time()时间戳（1970 起的秒数）import time; time.time() → 1758400000.0（示例值，每次运行都在涨）
time.sleep(秒)暂停time.sleep(1) → 暂停 1 秒后继续 # 脚本里"等一会"用
time.strftime(格式)格式化当前时间time.strftime("%Y-%m-%d %H:%M:%S") → '2026-09-21 14:30:00'（示例）
random.randint(a, b)随机整数（a~b，两头都包含）import random; random.randint(1, 6) → 1~6 的随机数

补一个字节串方法："你好".encode("utf-8") 得到字节串（b'...' 形式，这是合法写法——bytes 字面量只能直接写 ASCII，中文要先 encode）；subprocess 不设 text=True 时输出就是字节串，用 .decode("utf-8") 转回字符串（进阶篇场景 5 用到）。

文件对象三连（open / read / write / with）

准备材料（先照抄跑一次）：下面所有示例都读写同一个 a.txt，先创建它并写入两行：

with open("a.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")   # w 模式：不存在就创建（存在会清空，正好保证每次起点一致）

从空工作目录开始照抄：先跑这个准备框，再依次跑后面的 r / readlines / w / a 示例，任何一步都不会因文件不存在而中断。

with open("a.txt", "r", encoding="utf-8") as f:   # with = 自动关门，推荐写法
    内容 = f.read()                # 全读成一整个字符串
    #  同一文件对象读完一次就到末尾：read 之后再 readlines 通常得到空列表；
    #   要么二选一，要么重新 open，或 f.seek(0) 回到开头再读。

with open("a.txt", "r", encoding="utf-8") as f:
    行列表 = f.readlines()          # 按行读成列表

with open("a.txt", "w", encoding="utf-8") as f:
    f.write("内容\n")             # 写；\n = 换行

with open("a.txt", "a", encoding="utf-8") as f:
    f.write("追加一行\n")         # 追加：不清空原文
模式含义对照 Linux
"r"读cat
"w"写（ 打开即清空原文件）>（覆盖）
"a"追加（不清空）>>

字符串方法速查（11 个必会方法）

方法作用示例
s.split(符号)切开成列表"a,b,c".split(",") → ['a', 'b', 'c']
"符号".join(列表)列表拼成字符串"-".join(["a","b"]) → 'a-b'
s.strip() / strip("字符") / lstrip() / rstrip()去首尾空白；带参数=去首尾指定的字符" hi ".strip() → 'hi'
"%80%".strip("%") → '80'　".jpg".lstrip(".") → 'jpg'
s.replace(a, b)替换"a-b".replace("-", "_") → 'a_b'
s.upper() / lower()大小写"ab".upper() → 'AB'
s.find(x)找位置，找不到返回 -1"abc".find("b") → 1
s.startswith(x) / endswith(x)判断开头/结尾"a.log".endswith(".log") → True
s.count(x)数出现次数"abab".count("a") → 2
s.rsplit(符号, 次数)从右边切（取扩展名/最后一段）"a.b.c".rsplit(".", 1)[-1] → 'c'
s.isdigit()判断是不是纯数字"123".isdigit() → True　"12a".isdigit() → False
s.splitlines()按行切成列表（读命令输出必用）"a\nb".splitlines() → ['a', 'b']
