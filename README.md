# 九阶 Linux 与 Python 自学资料

> 面向零基础学习者的 Linux、Python、脚本自动化与基础排错资料

## 1. 这套资料是做什么的

这十七份资料用于完成一条从入门到实践的学习闭环（全套 **125 关**）：

1. 用教科书理解概念和基本操作；
2. 用基础练习册把知识练成可重复的操作；
3. 用进阶练习册完成带有故障现象的场景题；
4. 遇到函数、报错单词、日志、命名或 Git 操作时，使用对应手册查阅；
5. 用《17-关卡总表》按关卡打勾验收：做完一关勾一关。

它的核心目标不是覆盖所有开发或运维知识，而是帮助学习者建立以下能力：

- 在 Ubuntu 中使用终端、文件系统、权限、进程、服务、软件包和网络排查等基础能力；
- 使用 Shell 编写和运行简单的自动化脚本；
- 使用 Python 完成基础编程、文件处理、异常处理和简单自动化；
- 读懂常见报错和日志，按照“现象 -> 线索 -> 命令/代码 -> 验证”进行排查；
- 使用清晰的变量与函数命名，让脚本和代码保持可读、可维护；
- 使用 Git 完成本地提交并推送到 GitHub 的基本流程；
- 把脚本容器化、接上监控、部署进 K8s，并建立对 GPU 与 AI 推理的基本认识。

## 3. 推荐学习顺序

### Linux 主线

`01-Linux入门` -> `02-Linux练习册基础篇` -> `03-Linux练习册进阶篇`

建议每学完教科书的一部分，就做基础练习；基础练习稳定后，再做进阶场景。

### Python 主线

`04-Python入门` -> `05-Python练习册基础篇` -> `06-Python练习册进阶篇`

建议先掌握 Python 入门内容，再做基础题。进阶册中的网络、日志和远程操作场景，按题目标注的条件选择完成。

### 换轨说明（学程标注）

阶段 0~2 全程**不需要 Python**（Shell 脚本用不到 Python），Python 从阶段 3 的 `3-00` 门槛关开始——先拿 05 册的 20 道 ★题把基础快速过一遍。所以**先把 Linux 部分学完、回头再开 Python，也完全不会卡**。「入场 → 毕业」和「先学：X-X」都标在《17-关卡总表》与挂墙进度表上，跟着标注走即可。

### 进阶主线（阶段 4~8）

`07-Docker入门` -> `08-监控入门` -> `09-K8s入门` -> `10-综合项目` -> `11-AI与GPU入门`

学完 Python 主线（`3-17` 毕业）后按顺序推进；09 册在 Killercoda 在线沙箱里完成，不需要本地安装。

### 五份查阅手册

- `12-Python内置函数手册`：学习 Python 时随用随查；
- `13-报错英语单词手册`：看到陌生报错词时查阅；
- `14-日志报错解读手册`：排查命令或程序问题时查阅；
- `15-命名手册`：写变量、函数、脚本起名时随用随查；

## 4. 使用前提和默认环境

本仓库默认以 **Ubuntu 26.04 LTS（当前 LTS）+ Python 3.14** 为基准录制与实测（系统自带 Python，无需额外安装）；命令在 22.04 / 24.04 上同样通用——生产服务器上更常见的正是这两个版本。

使用者可以选择：

- Ubuntu 实体机；
- Ubuntu 虚拟机；
- 可通过终端或 SSH 使用的 Ubuntu 云服务器。

练习时请准备一个专用工作目录（如 `~/lab`），不要在重要系统目录或生产环境中直接尝试删除、覆盖、改权限或停止服务的命令；需要装第三方 Python 包时，请用虚拟环境（见第 4 份资料的附录 E）。

本套资料不要求 NVIDIA 显卡。GPU、CUDA 和大模型推理不是本套资料的基础学习前提。

部分题目有额外条件，不能把这些条件默认为每个人都已经具备：

- `systemd` 相关操作需要真正运行 systemd 的 Ubuntu 环境；不支持时按题目或答案中的环境限制说明处理；
- 网络请求题需要网络和可访问的目标接口；
- 真实 Nginx 日志需要 Nginx 或一份符合格式的日志文件，样例日志可用于基础分析；
- `paramiko` 远程巡检题需要 SSH 服务、网络连通性、账号和授权信息；
- 阶段 4 起的容器与部署题需要对应环境：Docker 与监控需要能装 Docker 的机器，K8s 用 Killercoda 在线沙箱即可；
- GPU 进程或真实推理服务题需要相应的 GPU、服务或外部实验环境（可用 Colab 等免费环境代替）。

## 5. 本套资料明确不包含的内容

以下内容可以作为后续学习方向，但不应理解为本套资料已经系统讲授：

- 生产环境的运维与安全加固：Nginx 部署调优、备份、安全审计等；
- 数据库、Web 框架、大型 Python 项目与系统化测试工程；
- 深度学习原理、大规模训练和生产级 AI 推理部署（第 11 份只做“看得懂、摸得着”的入门体验）；
- 完整的软件工程规范、代码评审与团队协作流程（**Git 的基础操作**已包含在第 16 份资料中）。

本套资料可以为上述方向提供 Linux、Python、脚本、容器与排错的基础，但学习这些内容仍需要另外的教材、环境或项目实践。

## 6. 每道题的建议做法

1. 先读题目，明确目标、限制条件和需要验证的结果；
2. 不看答案，先在实验目录中尝试；
3. 记录实际输入、输出和遇到的报错；
4. 再对照答案，重点比较思路、命令/代码和验证方法；
5. 做完涉及修改、删除、权限或服务状态的题后，把实验环境恢复到题目前的状态；
6. 动态内容例如 PID、时间、随机值、目录列表和系统版本可能不同，应比较结构和含义，不要求每个数字完全相同。
