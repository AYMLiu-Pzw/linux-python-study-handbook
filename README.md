# 九阶 Linux 与 Python 自学资料

> 面向零基础学习者的 Linux、Python、脚本自动化与基础排错资料。

## 1. 这套资料是做什么的

这九份资料用于完成一条从入门到实践的学习闭环：

1. 用教科书理解概念和基本操作；
2. 用基础练习册把知识练成可重复的操作；
3. 用进阶练习册完成带有故障现象的场景题；
4. 遇到函数、报错单词或日志时，使用对应手册查阅。

它的核心目标不是覆盖所有开发或运维知识，而是帮助学习者建立以下能力：

- 在 Ubuntu 中使用终端、文件系统、权限、进程、服务、软件包和网络排查等基础能力；
- 使用 Shell 编写和运行简单的自动化脚本；
- 使用 Python 完成基础编程、文件处理、异常处理和简单自动化；
- 读懂常见报错和日志，按照“现象 -> 线索 -> 命令/代码 -> 验证”进行排查；
- 为后续学习 Docker、远程运维、部署和更复杂的项目打基础。

## 3. 推荐学习顺序

### Linux 主线

`1-Linux入门` -> `2-Linux练习册基础篇` -> `3-Linux练习册进阶篇`

建议每学完教科书的一部分，就做基础练习；基础练习稳定后，再做进阶场景。

### Python 主线

`4-Python入门` -> `5-Python练习册基础篇` -> `6-Python练习册进阶篇`

建议先掌握 Python 入门内容，再做基础题。进阶册中的网络、日志和远程操作场景，按题目标注的条件选择完成。

### 三份查阅手册

- `7-Python内置函数手册`：学习 Python 时随用随查；
- `8-报错英语单词手册`：看到陌生报错词时查阅；
- `9-日志报错解读手册`：排查命令或程序问题时查阅。

## 4. 使用前提和默认环境

本仓库默认以 Ubuntu 为学习环境，使用者可以选择：

- Ubuntu 实体机；
- Ubuntu 虚拟机；
- 可通过终端或 SSH 使用的 Ubuntu 云服务器。

通常需要安装 Python 3，并准备一个用于练习的工作目录。练习时应优先使用教材指定的实验目录，不要在重要系统目录或生产环境中直接尝试删除、覆盖、改权限或停止服务的命令。

本套资料不要求 NVIDIA 显卡。GPU、CUDA 和大模型推理不是九册的基础学习前提。

部分题目有额外条件，不能把这些条件默认为每个人都已经具备：

- `systemd` 相关操作需要真正运行 systemd 的 Ubuntu 环境；不支持时按题目或答案中的环境限制说明处理；
- 网络请求题需要网络和可访问的目标接口；
- 真实 Nginx 日志需要 Nginx 或一份符合格式的日志文件，样例日志可用于基础分析；
- `paramiko` 远程巡检题需要 SSH 服务、网络连通性、账号和授权信息；
- GPU 进程或真实推理服务题需要相应的 GPU、服务或外部实验环境。

以下内容可以作为后续学习方向，但不应理解为九册已经系统讲授：

- Docker、Docker Compose 和容器化部署；
- GPU、CUDA、模型训练和完整的 AI 推理部署；
- 生产环境的 Nginx 部署、监控、备份和安全加固；
- Git/GitHub、Markdown 协作流程和完整的软件工程规范；
- 大型 Python 项目、数据库、Web 框架和系统化测试工程。

九册可以为上述方向提供 Linux、Python、脚本和排错基础，但学习这些内容仍需要另外的教材、环境或项目实践。

## 6. 每道题的建议做法

1. 先读题目，明确目标、限制条件和需要验证的结果；
2. 不看答案，先在实验目录中尝试；
3. 记录实际输入、输出和遇到的报错；
4. 再对照答案，重点比较思路、命令/代码和验证方法；
5. 做完涉及修改、删除、权限或服务状态的题后，把实验环境恢复到题目前的状态；
6. 动态内容例如 PID、时间、随机值、目录列表和系统版本可能不同，应比较结构和含义，不要求每个数字完全相同。

## 7. 打印使用说明

每份资料都是 HTML 文件，可以用浏览器阅读或打印：

1. 打开目标 HTML 文件；
2. 使用浏览器的打印功能；
3. 纸张选择 A4；
4. 缩放保持 100% 或浏览器默认值，不要再额外压缩；
5. 源文件已设置约 13 mm 上下边距和 12 mm 左右边距；
6. 需要保留彩色标题、警告和代码背景时，开启“打印背景图形”；
7. 第一次打印建议先另存为 PDF，检查标题、题目、答案、代码、表格是否被分页截断，再批量打印。
