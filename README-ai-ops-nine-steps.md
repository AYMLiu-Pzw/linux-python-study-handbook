# 九阶 · Linux 与 Python 自学丛书

> 零基础自学 Linux 与 Python 的九册书：教科书 + 练习册 + 工具手册。

---

## 这是什么

这是一套**按"学 → 练 → 查"闭环设计**的自学教材：

| 角色 | 册数 | 作用 |
|---|---|---|
| 📖 教科书 | 2 本 | 从零讲起：每个概念先讲"是什么、为什么存在"，再给"输入 → 输出 → 解读"示范 |
| ✏️ 练习册 | 4 本 | 每题只给目标、不给答案；答案集中在书末，按"①先想什么 ②为什么用这个命令 ③完整步骤 ④怎么验证做对了"四步展开 |
| 📕 工具手册 | 2 本 | 报错单词、报错解读——遇到就查，查多了自然记住 |
| 🗂️ 基础背诵 | 1 本 | 高频单词、常见报错句，碎片时间背诵 |

## 学习路径（怎么用）

```
第 1 步：1-Linux入门 学一章 → 2-基础篇 做对应阶段 → 3-进阶篇 场景演练
第 2 步：4-Python入门 学一章 → 5-基础篇 做对应阶段 → 6-进阶篇 场景演练
第 3 步：8、9 两本手册随时翻；7 在学 Python 时对照
```

**三条纪律**：

1. 顺序不能反：教科书是学习，练习册是检验
2. 练习册每题**先自己想再看答案**；★ 必做，☆ 按自检规则（一次做对就跳过）
3. 每章学完，把心得和踩坑记进学习日志仓库（见下）

## 设计特色

- **先理解再记忆**：每册第一页是"理念篇"，先讲构造和规律，再进干货
- **工单式场景**：进阶册把练习伪装成真实工作（"你是 AI 组新运维，服务起不来，去处理"）
- **★/☆ 分级 + 自检跳题**：省时机制，做对就跳，卡壳补做
- **安全红线**：实验只碰 `~/lab` 与 `/tmp`，危险命令紧邻警告与恢复步骤
- **可打印**：A4 版式，正文/注文字号区分，颜色按真实终端与代码配色
- **示范可复现**：所有输出来自真机实测；动态值（PID、时间、目录列表）一律标注"以实际为准"
