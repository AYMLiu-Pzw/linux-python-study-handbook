第 1 页 · 起名三原则

变量名不是给电脑看的，是给读代码的人看的。做到下面三条，代码的可读性会明显不一样。

原则人话解释❌ 别这样✅ 这样写
1. 见名知意一眼看出里面装的是什么x　a1　data2total_count　disk_usage
2. 下划线连接全部小写，用下划线连；别用拼音缩写diskUsage　panYongLvdisk_usage　user_name
3. 判断用 is_/has_值只有 True / False 的，一眼看出是"是不是"empty　err_flagis_empty　has_error

⚠ 坑 1：别把 Python 内置名当变量名

下面这些词 Python 已经占用。再拿它们当变量名，等于把原有功能“覆盖”掉：

list　dict　str　int　float　bool　len　sum　max　min　input　print　open　type　id　next　all　any　set　object

❌ list = [1, 2]（写完这句，以后 list() 就废了）
✅ data_list = [1, 2]　✅ total_sum = 100　✅ max_value = 9

解法就一句话：加前缀或后缀——data_、total_、_value、_list，立刻不撞。

⚠ 坑 2：pwd 有歧义

Linux 里 pwd = 显示当前目录。所以表示“密码”时写全称 password，别用 pwd——同一个词两个意思，读代码的人会懵。

第 2 页 · 怎么起名：四步法

① 先用中文说清楚：这个变量装的是"磁盘用了百分之几"。

② 圈出关键词：磁盘 → disk ｜ 使用率 → usage

③ 判断类型，挑词形：

· 装"东西"（名词）→ 名词组合：disk_usage

· 是"是不是"（只有 True/False）→ 加 is_/has_：is_disk_full

· 要做"动作"（函数）→ 动词开头：check_disk()

④ 连起来、读一遍：全小写 + 下划线，读起来能一眼看懂。

拿不准就用全称，不要自造缩写：message 就写 message（别写 mssg），password 就写 password（别写 pwd）。

📌 命名检查三连问（起完名默念一遍）

① 别人一眼能看懂吗？　② 有下划线分隔吗？　③ 撞内置名了吗？

三个都过，这个名字就合格。　背诵顺序：核心 24 词 → is_ 判断组 → 动作动词组（写脚本 90% 的命名来自这三块）。
