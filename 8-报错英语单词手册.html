第 1 页 · 理念篇：报错英语的构造规律

1. 报错就是"简单句"，倒着读就懂

计算机的报错大多是"简单句"：什么东西 + 怎么了 + 对象。中文习惯"找不到文件"，英文是"文件没被找到"。把英文倒过来装回中文语序，意思立刻出来——这是辅助记忆规律，不是唯一结论：最终判断还要结合完整报错、退出码和命令行为。

报错原文逐词中文顺序
File not foundFile(文件) + not(不) + found(被找到)找不到文件
Permission deniedPermission(权限) + denied(被拒绝)权限被拒绝 = 没权限
Connection refusedConnection(连接) + refused(被拒绝)连接被拒绝 = 对方没开门
No space left on deviceNo(没有) space(空间) left(剩下) on(在) device(设备)设备上没剩空间 = 磁盘满了

2. 规律一：-ed 结尾 = "被…了"（报错的灵魂）

很多常见报错中的过去分词或形容词形式以 -ed 结尾，但不是全部；不要把这个规律当成绝对语法：

单词意思出现在
denied被拒绝（deny 拒绝）Permission denied 没权限
refused被拒绝（refuse 拒绝）Connection refused 连不上
failed失败了（fail 失败）Installation failed 安装失败
terminated被终止（terminate 终止）Process terminated 进程被结束
killed被杀掉Killed by OOM 被内存不足杀死
closed被关闭Connection closed 连接被关闭
ignored被忽略Warning ignored 警告被忽略
skipped被跳过Package skipped 软件包被跳过

3. 规律二：前缀是"方向盘"，词根是"发动机"

英语单词 = 前缀 + 词根 + 后缀。认识前缀和后缀，不认识的长单词也能猜个七八成：

前缀/后缀意思举例
un- / in- / im- / dis- / non-不、否定unknown 未知 · invalid 无效 · disabled 被禁用
re-重新、再次restart 重启 · retry 重试 · reconnect 重连
pre-预先preinstall 预装
mis-错误的mistake 错误 · misconfigured 配置错了
-er / -or做…的（人/工具）server = serve(服务)+er → 提供服务的机器
-ion / -tion名词化connection = connect(连接)+ion
-able / -ible可以…的available 可用的 · executable 可执行的
-ory / -ary场所、地点directory = direct(指引)+ory → 指引放东西的地方=目录

背单词联想技巧（把长单词拆成认识的小块，联想记忆，不必较真词源）：

• denied → deny(拒绝) + ed(被…) = 被拒绝

• unreachable → un(不) + reach(到达) + able(能) = 不能到达 = 不可达

• available → avail(有用) + able(能) = 有用的 = 可用的

• connection → connect(连接) + ion(名词化) = "连接"这件事

规律：大部分技术单词都是"词根+前后缀"拼出来的，先拆块、再拼意思，比死记快 3 倍。

4. 读报错四步口诀

① 先找否定词：not / no / denied / failed / refused / error（红色的就是）

② 再找主语：谁出事了？file？connection？permission？

③ 按"主语 + 怎么了 + 对象"翻译出来

④ 看不懂就先翻本手册 A 组查对应条目，还不行再联网搜索（外部扩展：把整句报错复制去搜；断网时先记录原文，回网再查）

综合练习 · 看报错猜意思（6 题，先猜再看答案）

1. No such file or directory（提示：such）
2. Permission denied（提示：-ed）
3. NameError: name 'data' is not defined（提示：defined）
4. IndexError: list index out of range（提示：index / range）
5. ModuleNotFoundError: No module named 'requests'（提示：module）
6. Connection timed out（提示：time / out）

自检规则：6 题全对 → 你已经掌握报错英语的骨架，进入"遇到就翻"阶段；错 1-2 题 → 回去重读理念篇规律一、二；错 3 题以上 → 从 A 组开始重新背。

综合练习答案（先做再看，与题目分页隔离）

第 1 题：没有这样的文件或目录（such=这样的）

第 2 题：权限被拒绝（denied=被拒绝）

第 3 题：变量 data 没定义就用了

第 4 题：索引超出范围（index=索引、range=范围）：访问列表/字符串时下标超过了它的长度。题面只给了报错原文，具体是"取到第几个"要看当时的代码和列表长度——单凭这一行报错猜不出具体数值。

第 5 题：没安装 requests 这个模块
